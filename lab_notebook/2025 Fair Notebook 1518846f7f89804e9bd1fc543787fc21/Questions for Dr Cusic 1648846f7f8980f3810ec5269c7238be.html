Project Overview

My project aims to generate brain MRI scans with four modalities (t1n, t1c, t2w, t2f) using labeled masks as conditioning. The scans are generated by a diffusion model, an image-to-image model that learns how to generate realistic structures. This is a helpful overview of diffusion if you’re interested. My adaptation of a medical diffusion model, Med-DDPM, allows the model to be conditioned or “instructed” by a labeled mask with desired features (e.g., a non-enhancing tumor core).

An example mask and corresponding t1n scan in the BraTS2024-Adult Glioma dataset used for training the diffusion model looks like this:

In any given mask like the one at left for BraTS2024-Adult Glioma, there are six possible integer grayscale values: 0,1,2,3,4,5, each corresponding to a distinct region or element. The labels are: 

0 - background
1 - head
2 - enhancing tissue
3 - non-enhancing tumor core
4 - surrounding non-enhancing FLAIR hyperintensity
5 - resection cavity

Once I’ve trained a model capable of generating high-fidelity scans given a mask (my current model achieves high visual fidelity but needs more validation), there becomes a need for abundant masks. One approach from the original Med-DDPM paper is to transform parts of the masks, either through shifting or scaling. For example, one transformation may be scaling some tumor by a factor such that it doesn’t escape the head region.

While transformations like these were done in their paper without concern, they bothered me a bit. How did the authors know if such a scaled tumor could even exist in the regions it was scaled to occupy? If there are all sorts of unrealistic features in their masks, and therefore scans that are used to train other models downstream (e.g., to automatically annotate tumors), fidelity seems crucial. So, with that, my questions for you are:

  • Scaling: is scaling a tumor/tissue/cavity/hyperintensity relative to its origin by a random factor between 12\frac{1}{2}21​﻿ and 222﻿ appropriate, so long the scale factor does not push it outside of the head? Does this depend on what’s being scaled?
  • Shifting: are there specific regions of the brain that certain labels cannot exist in?
    Are there specific relationships or proportions between regions (e.g., enhancing tissue relative to non-enhancing tumor core) that should be preserved?
  • What other advice/caution would you advise when making these transformations to ensure I don’t create anatomically inaccurate masks?

Lastly, I had one question about evaluating generated scans: prior to a formal evaluation, are there efficient methods a neuroradiologist would use to spot anatomically unrealistic features in these types of generated scans that I could leverage?
